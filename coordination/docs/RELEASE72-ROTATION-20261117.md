# 1.0.72 手动旋转校准测试包

## 使用方法

顶部菜单 → “旋转屏幕180°”。点击后切换正向或反向横屏，再点一次可切回。选择会保存，重新打开游戏继续使用选定方向。窗口、原生游戏画面和触摸操作通过Android窗口方向同步处理。

功能菜单采用两列六行，共11项。帧率显示继续使用小字样式。

## 黑屏诊断

诊断报告新增实际APK文件的SHA256、直接解析APK的版本、包更新时间，以及导出进程和游戏主进程PID。这些信息用于核对用户实际安装版本及对应日志。

realme场景主体黑屏原因继续定位。可先将玩法金手指全部取消，保存并按提示退出后重开，观察画面。故障出现时，长按应用图标 → 导出诊断报告，再发送新的ZIP。
