# 1.0.72 更新说明

覆盖安装 FFRS-1.0.72-universal.apk。已有游戏数据继续使用，游戏数据版本和DLC由实际内容识别。

## 本轮更新

- 接入四向重力感应，支持两个横屏与两个竖屏方向。
- 菜单增加“旋转屏幕180°”手动校准，游戏画面和触摸覆盖层共同翻转，保存选择并在重开时恢复。
- Surface尺寸变化时重新发布原生窗口代次，使呈现路径按当前尺寸重新计算画面比例。
- 诊断报告增加实际APK摘要、APK版本、安装更新时间与导出/游戏进程身份。
- 延续1.0.71的小字帧率显示、两列菜单与内置金手指。

## 使用提示

自动旋转需要系统支持。在荣耀平板PC模式下，实测出现方向受系统接管的情况，退出PC模式后用户确认可自动旋转。
