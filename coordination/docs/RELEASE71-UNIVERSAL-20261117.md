# 1.0.71 更新说明

## 本次更新

- 帧率显示缩小约58%，背景随文字宽度收紧。顶部菜单提供显示开关，并记住选择。
- 功能菜单调整为两列五行，十项功能均可完整显示和点按。
- 内置资源包的五项玩法金手指，包括移动速度2倍、不遇敌、战斗掉落率100%、战斗经验2倍、战斗金币2倍。默认全部关闭，逐项勾选使用。
- 不遇敌开启后，按住R3临时恢复正常遇敌，松开继续不遇敌。R3是右摇杆按下。
- 金手指窗口保留“角色存档修改”入口，包含中文角色名和原有数值编辑功能。
- 补齐窗口恢复时的纹理索引获取，以及界面重建后的存档目录延续。

## 金手指如何生效

1. 在顶部菜单打开“金手指”，勾选所需玩法功能，再点“保存”。
2. 按提示先在游戏内保存进度。准备好后点“退出游戏”，再重新打开应用，新设置生效。
3. 取消某项勾选并保存，退出后重新打开，即可恢复该项原始行为。
4. 使用“角色存档修改”时，按窗口提示修改并保存，再返回标题画面重新读取该存档生效。

五项玩法开关适配1.0.1游戏数据。APK会校验游戏版本和原始指令。现有1.0.0数据可使用角色存档修改，升级到1.0.1数据后可使用上述玩法开关。

## 安装与数据

安装 `FFRS-1.0.71-universal.apk`。已有用户覆盖安装即可，游戏数据继续放在内部存储的 `FFRS` 目录。APK适配现有1.0.0无DLC数据和1.0.1数据，DLC由实际安装内容识别。游戏数据升级及DLC仍通过对应数据包安装。
