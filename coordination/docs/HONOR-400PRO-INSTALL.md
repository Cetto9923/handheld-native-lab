# 《最终幻想：共鸣》荣耀 400 Pro 安装说明

本包供用户自己的设备私下安装。游戏数据、生成 shader、APK 和存档不进入 Git，也不上传公开仓库。

这是普通游戏流程验证版。荣耀平板已复验教程暗魔法、完整 Limit 的冰晶/雷电/火焰/光束；荣耀 400 Pro 尚未实测。配置目标为 60 帧，不能把目标值或屏幕刷新率当作稳定 60 帧。蓝牙音频依用户要求记为未验收。

## 准备文件

- `FFRS-Honor-1.0.1.apk`：安装程序，包名 `org.ffrs.gamewindow`。
- `FFRS-data.zip`：游戏数据，解压后最外层是 `FFRS` 文件夹。
- `data-manifest.json` 和两个 `.sha256` 文件：文件清单及传输校验。

推荐先在电脑解压数据包，再将整个 `FFRS` 文件夹复制到手机内部存储根目录。手机需要容纳约 17 GB 解压数据；若同时在手机保留 ZIP 和解压文件，需要两份空间。精确大小以交付清单为准。

## 安装与首次启动

1. 将完整 `FFRS` 文件夹放到手机的“内部存储”根目录。不要再套一层 `FFRS`。
2. 在手机点开 `FFRS-Honor-1.0.1.apk`，按系统提示允许此来源安装，然后安装。
3. 打开“最终幻想：共鸣”。若出现数据检查页，点“授予文件访问权限”，在系统页允许本应用访问所有文件，再返回应用，点“重新检查游戏数据”。
4. 保持应用在前台，等待首次 shader/资源准备，进入标题页后正常开始游戏。后续启动会复用缓存。标题页的 `1.0.0.0` 是原游戏版本；安装包版本在系统“应用信息”中查看。

目录应为：

```text
内部存储/
└── FFRS/
    ├── main.nso
    ├── sdk.nso
    ├── romfs/
    ├── shaders.hnla
    └── shaders/        （11 个修复文件，务必完整保留）
```

不要把 ZIP 本身当作已经安装的数据。若手机解压器不支持大文件 ZIP，请在电脑解压后复制整个文件夹。

## 更新、操作与验收

已有同包游戏时直接覆盖安装，保留应用数据。不要先卸载或清除应用数据；存档在应用专属目录，不在本数据包中。不同签名提示冲突时停止安装，保留原应用和存档，不以卸载解决。

触控按键可通过画面上方 `PAD` 显示/隐藏；也可连接手柄。不要从平板复制诊断 marker、缓存或存档文件来“配置”新手机。

在 400 Pro 首次运行时，请分别检查暗魔法蓝白核心与紫红外圈、Limit 的蓝冰晶与火焰收尾、BOSS 出场碎石，以及野外/战斗声音。当前包没有完成 400 Pro 的视觉、实际帧率或蓝牙音频验收。

## 找不到数据时

确认 `main.nso` 与 `romfs` 位于同一层，且 `romfs/FFRS/Content/Paks/` 内容完整。重新授予文件访问权限并回到应用检查；缺文件时重新复制对应数据，不清除应用数据。安装包及数据 SHA-256 应与同一份交付清单一致。
