最终幻想：共鸣 安装与使用（荣耀400 Pro）

一、放数据
在电脑解压 FFRS-data.zip，将得到的整个 FFRS 文件夹复制到手机“内部存储”的第一层，与 Download、DCIM 文件夹同层。

正确位置：内部存储/FFRS/
文件夹内应有：main.nso、sdk.nso、romfs、shaders.hnla、shaders。
不要多套一层 FFRS，也不要把 ZIP 当作已解压的数据。完整数据约 17GB。

二、安装
将 FFRS-Honor-1.0.2.apk 复制到手机，点击安装；按系统提示允许此来源安装应用。
打开“最终幻想：共鸣”。若提示文件权限，点击“授予文件访问权限”，允许本应用管理所有文件，返回后点击“重新检查游戏数据”。

三、使用
首次启动保持应用在前台，等待资源准备完成。
标题页选择 New Game 开始游戏；有存档时选择 Continue 继续。
点击画面顶部 PAD 显示或隐藏触控按键，也可连接手柄操作。

找不到数据时，先检查路径是否为“内部存储/FFRS/main.nso”，并确认上述文件和文件夹均已完整复制。
