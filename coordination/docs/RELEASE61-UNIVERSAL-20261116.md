# 共鸣1.0.61转场修复候选

安装FFRS-1.0.61-preview-universal.apk，继续使用现有游戏数据和存档。APK沿用新旧主模块及实际DLC文件识别机制，旧无DLC数据和新含DLC数据共用安装程序。

## 本轮测试

索尔用户先保存已有进度并退出，覆盖安装APK，重新新建游戏推进至视频中的传送门剧情。确认剧情结束后可以进入下一场景并操作角色，再反馈结果。

如果再次退回桌面，先长按游戏图标，选择“导出诊断报告”，保存FFRS-report-日期时间.zip并发回。日志需先于下一次启动游戏导出。

## 验证范围

本版修正已证明只用Fetch/Gather等读取方式的绑定被线性过滤能力检查拒绝的问题，并隔离对应的采样器及图像描述符缓存。日志缺少原失败纹理的具体着色器绑定映射，索尔本机是否由这处缺口触发，须通过上述转场复测确认。

Android构建与108项宿主检查通过，覆盖三项新增采样用途回归、真实着色器验证及两个负对照。6项可选真实shader旧fixture输入缺失，标记SKIPPED。平板场景回归等待用户完成空之轨迹测试，索尔实机与独立QA尚待执行。该包放在发布目录的“待验证”子目录供复测。
