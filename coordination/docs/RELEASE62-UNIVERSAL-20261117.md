# 共鸣 1.0.62 闪退修复预览

安装 FFRS-1.0.62-preview-universal.apk，已有用户在游戏内保存并退出后直接覆盖安装。

本版补齐缺少 R32 浮点线性过滤能力的设备兼容路径，针对索尔用户开场火场最终BOSS后、紫色传送门剧情进入第二幕时的退出问题。使用浮点插值保留原数据精度，并接通预热和缓存身份。

沿用现有新旧数据识别与DLC扫描，旧1.0.0无DLC数据和1.0.1含DLC数据共用此APK。需要升级游戏内容的用户继续按既有数据包说明导入。

## 索尔用户复测

覆盖安装后推进到火场最终BOSS结束后的紫色传送门，检查剧情后能否进入第二幕并操作角色。

如果退回桌面，请在再次进入游戏前长按游戏图标，点“导出诊断报告”，将生成的 FFRS-report-日期时间.zip 发回。
