# 共鸣1.0.63预览版更新说明

默认取消额外的宿主帧率限制，旧发行默认30/60设置在升级后迁移至不限帧，之后仍可使用已有显式限帧标记。沿用当前分辨率策略和游戏原有时间逻辑。最终帧率取决于具体场景、硬件和驱动，刷新率请求与实际游戏帧率分别记录。

本版按内存压力下优先保住游戏进程的方向改造。每半秒主动检测内存，压力升高时停止后续预热，释放可重建缓存，并在GPU完成使用后清理空闲资源。该过程可能带来短暂停顿或之后首次技能编译停顿。

回收后按实际RSS增长决定再次清理，减少常驻工作集被反复清空重建。系统持续低内存且回收收益很小时延长重试间隔，压力升级和明确系统通知继续处理。修正诊断日志写满后停止更新的问题，保留最近两个有界窗口及独立fatal记录。

输入基线为1.0.62，保留新旧数据及实际DLC识别机制。索尔1.0.62战斗人影闪烁继续单独追踪，当前候选尚未完成该场景显示验收。

## 安装

已有用户在游戏内保存并退出后，覆盖安装FFRS-1.0.63-preview-universal.apk即可。继续沿用现有游戏数据和存档。新用户按发布目录的安装说明放置FFRS-data.zip中的完整FFRS目录。

沿用62的新旧数据包识别机制，DLC按设备上的实际内容加载。此次数据包无需重新下载，本地发布目录的完整ZIP共40550项已全部通过CRC校验。

## 实测范围

源码4c7fd86的Android打包和111项宿主检查通过，653项源码输入前后摘要一致。RG477M安装回读通过，并使用隔离存档读档进入土之神殿。

解锁前构建首次主动回收释放约222MiB RSS。神殿场景注入强压力通知后释放约143.8MiB，之后仍能移动。该构建神殿8秒移动实测约19.06FPS。高负载场景的实际帧率仍待继续优化，系统仍可能在内存不足时终止应用。

故障原机低内存退出、索尔人物闪烁和小米长停顿仍待对应设备复测。蓝牙连续音频、热插拔与独立QA本轮未运行。
