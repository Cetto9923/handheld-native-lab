# 工作 Agent 回报模板

每次交回或中断写一个 `Txx-role-YYYYMMDD-HHMM.md`，由该任务工作者独占写入。清理凭据、密钥内容及无关个人信息后再入库。

```text
任务ID / 角色 / 实际Agent身份：
当前状态（IN_PROGRESS / SELF_TESTED / PASS / FAIL / BLOCKED / NOT_RUN）：
目标与实际做了什么：
分支 / worktree / HEAD / dirty及untracked：
输入身份（游戏版本 / 模块 / 哈希范围）：
修改文件 / 构建ID / 产物路径与摘要：
运行命令 / cwd / 工具版本 / 退出码：
原始日志、画面、帧时间数据路径：
观察 / 推断 / 未知分别是什么：
验证结果与覆盖范围：
失败尝试（避免下一位重复）：
存活进程、PID、日志和恢复命令：
下一步前三条可执行命令：
待释放或转移的写入范围：
残留风险 / 独立QA是否已复跑：
```

QA 的独立复跑另写报告，不能简单复制实现者的 PASS。大型原始证据在 `.local/`；入库报告保留路径、摘要、采集条件和再生成方法。不要把本机被 Git 忽略的产物说成已备份。
