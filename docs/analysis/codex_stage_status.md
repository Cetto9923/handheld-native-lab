# 原生移植阶段验收：尚未进入可玩阶段

验收目标为 RG477M 上实际游戏启动、标题、可操作场景、输入、音频、存读档及持续帧率；单函数测试与诊断 APK 只证明其中的基础设施。

| 阶段 | 当前真实证据 | 尚缺的验收 |
|---|---|---|
| 加载器及真实入口 | 主模块可映射，解析 651 个导入、4,612 条 RELA、1,370,974 条 RELR；原始 44 字节函数在 Mac ARM64 的 16,875 组输入与数学参考零差异。`nnMain` 已越过地址预留和互斥量初始化，当前在未实现 `atexit` 严格停止，退出 133。 | 完整 CRT/TLS、线程和平台接口；完整启动；Switch/可信参考环境对照及 Android 执行。T02 尚未通过。 |
| 资源 | 既有清单、流式提取工具和本地素材保留。 | 游戏实际文件系统挂载、资源解压与运行时使用；不能把文件存在视为加载成功。 |
| Android ARM64 / APK | 真实 AArch64 ELF 与已签名 `org.ffrs.diagnostic` APK，DEX/JNI、Manifest、签名、16 KiB LOAD 对齐静态检查通过。 | 安装和设备执行；当前是诊断宿主，未集成完整游戏启动。部分官方工具链可重建，完整 NDK 包校验未完成。 |
| 图形 / 标题 | NVN 有类型分发与缺失报告可用；535 个名字中 2 个查询入口可解析、533 个未实现。 | 实际 Vulkan 后端、资源/队列/着色器/呈现及真实标题。两个入口不构成渲染支持。 |
| 可玩场景 | NOT_RUN。 | 标题之后真实场景、操作流程和正常退出。 |
| 输入 / 音频 / 保存 | 诊断 UI 已有手柄事件、生命周期与 app-private 临时文件往返检查代码。尚未在设备执行。 | 游戏输入映射、真实音频、游戏存读档；临时文件测试不能替代存档。 |
| 真机 / 性能 / 稳定性 | ADB 列表为空。 | RG477M 实测 Vulkan、驱动、分辨率、30 FPS 帧呈现与 45 分钟运行，均 BLOCKED_DEVICE / NOT_RUN。 |

此前“总体约 10%～15%”只能是按最终可玩目标给出的粗略工程判断，不是代码量、任务卡或工时统计。这次补齐了真实打包和运行时基础设施，但最高风险的完整启动、图形与可玩性仍未验证，目前没有足够证据明显提高该估计。

测试原始输出与真实退出码在 `.local/runtime/`、`.local/host-verification/` 和 `.local/logs/android/`。当前检查点与精确恢复命令见 [HANDOFF](../../coordination/HANDOFF.md)。独立 QA 被平台安全检查中止，未取得完整独立验收，不记为通过。
