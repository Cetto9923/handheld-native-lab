# NVN → Vulkan 底座有界评估

**结论：有真实可复用的 GPU/着色器代码，但本次两个候选均未提供可直接接入的 NVN ABI 桥。建议复用外部底座，并明确由具备 Switch GPU、shader 编译和 Android Vulkan 经验的图形负责人主导。** 从零自研并非不可选，但等于承担同等级后端与编译栈工作；若现有团队没有该专长，就需要引入人工图形专家。继续增加外围探针不能补齐这些实现。此为基于下列源码边界的工程判断，不是可玩性或工期承诺。

项目基线采用本次交接：535 个 NVN 名字/typed dispatch、2 个查询、0 个 backend，完整游戏入口尚未到 NVN；本轮未新建或运行 probe。核验时间：2026-10-23 UTC，仅公开 primary 源码、元数据和许可证。
