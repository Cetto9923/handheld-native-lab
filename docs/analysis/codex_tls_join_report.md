# TLS 最小静态单元收尾：0x32221bc 与 0x30318

本轮只读 main，复用断连前已成功保存的 `.local/cfg-units-v1`，没有重生成切片。原输入前后 SHA-256 均为 `6e6d1f3cd1672243e2ed344cc1b8849b85437d41bdecec81a5f9181e472d68a5`。未运行游戏、ADB 或写任何 TP/SDK/原仓库。环境恢复后先核对日志存在、原字节切片 SHA 与各编译/反汇编退出码，再继续研究。

## 0x32221bc：局部直接 CFG 已闭合

扫描 main 全部 99,000,832 字节 text 中的直接 B、BL、B.cond、CBZ、CBNZ、TBZ、TBNZ 编码。进入 `[0x3222194,0x32221f0)` 的直接边只有：

| 分支 PC | 目标 | 类型 |
|---|---|---|
| `0x3222138` | `0x3222194` | B.GT |
| `0x322213c` | `0x3222194` | B.LS |

没有直接边跳入常量定义序列 `0x32220fc..0x3222130` 的中部。两条入边之前的最后定义是：

| 定义锚点 | 到达值 |
|---|---|
| `0x32220fc/0x3222100/0x322210c` | x9=`0x250` |
| `0x3222110/0x3222114/0x3222120` | x8=`0x258` |
| `0x3222124/0x3222128` | x0=`0x238` |

两条直接路径之间及 join 到 MRS 之间没有重写这三个寄存器。`0x3222190` 是无条件 B 到 `0x3222170`，故等待环不会落入 `0x3222194`。回边 `0x3222628/0x3222634` 去 `0x32221f0`（MRS 和地址形成之后）；`0x3222638` 去等待/退出区域 `0x3222144`，不会重新执行 MRS。

在结构包络 `[0x3221ea0,0x3222ab0)` 的逐指令直接 CFG 内，节点删除检查确认上述定义均支配 MRS；从等待块 `0x3222144` 或后循环块 `0x32221f0` 均无直接 CFG 路径再次到达该 MRS。因此这一单元可从“汇入值未证明”收敛为：

| PC | 结果 |
|---|---|
| `0x32221bc` | x10=TP |
| `0x32221c0` | x27=TP+`0x258` |
| `0x32221c4` | x8=TP+`0x238` |
| `0x32221c8` | `[sp+0x30]=TP`、`[sp+0x38]=TP+0x238` |
| `0x32221e0` | x21=TP+`0x250` |

这是**局部直接 CFG**结论：包络来自序言、尾声和 cold blocks 的结构，不是恢复的原始符号/FDE 边界。调用按普通返回后的 fallthrough 建边；间接跳入、异常/信号转移、修改代码或运行可达性均未证明。不能据此推广全程序无 header 访问。

## 0x30318：复制当前指针值并登记目标字段的析构

可见小函数包络为 `[0x30318,0x303cc)`，有配对序言/尾声及两条 RET（`0x30364`、`0x303c8`）；`0x303cc` 开始另一段函数代码。原始类型/函数名未知。

1. `0x30324` 把入口 x0 保存到 x19；`0x30338` 读取 TP 到 x20。
2. `0x3033c` 读取 `mem8(TP+0x270)`；`0x30340` 在 bit 0 清零时转入登记路径。
3. 已登记路径在 `0x30354/0x30358` 执行 `mem64(TP+0x268)=mem64(input_x0)`，然后返回。
4. 首次路径 `0x3038c` 经 PLT `0x5e682e0`、GOT `0x7772408` 对应导入 #130 `__cxa_thread_atexit`，实参 x0=`B+0x303e0`、x1=`TP+0x268`、x2=`B+0x771ba00`。
5. 返回值于 `0x30390` 被 MOVZ 覆盖，原代码未检查；`0x303a4` 写 `mem8(TP+0x270)=1`，随后 `0x303b8/0x303bc` 再复制入口指针字段的当前值。

当调用者传入 `TP+0x250` 时，这里把该字段里的**指针值**复制到 `TP+0x268`，并为后者登记回调；没有把传入字段地址保存在可见单元内。已置位后再次调用仍会刷新复制值。这说明该调用不能按无状态/no-op 适配。

直接可见 TP 范围为 `+0x268` 的八字节字段、`+0x270` 的一字节标志；均不与现有候选模板边界矛盾。回调 `0x303e0` 的完整清理行为、`__cxa_thread_atexit` 实现/失败策略、DSO token 原始类型、重入和退出顺序仍在本单元之外，至此停止扩展。
