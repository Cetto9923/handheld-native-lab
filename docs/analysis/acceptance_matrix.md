## 0. 引擎版本基线修订声明（重要）

T00 报告写「**UE 5.4**」。T00R 独立复核在 `.local/uncompressed/main.bin` 中找到链接器写入的
模块标识串：

```
SDK MW+EpicGames+UnrealEngine-5_6_1          偏移 108,874,700
```

⇒ 引擎基线应为 **UE 5.6.1（直接证据，非推断）**。

**因此：凡下表标记 `⟨UE5.6.1⟩` 的条目，其实现假设、符号名、反射名、序列化/资源格式、
渲染器与着色器版本判定，一律以 UE 5.6.1 为准，不得沿用 UE 5.4 的结论。**
T01 路线文档、T02 样例卡、T04 加载链实现需同步修订。

同时澄清（T00R 已独立复核）：`sdk` = Nintendo SDK 20.5.17 **NVN** 图形栈（+ libz / nnSdk /
64-bit build target）；`subsdk0` = Nintendo SDK 20.5.17 **movie**（多媒体/视频）；
`rtld` = Nintendo 运行时加载器（`nnrtld.nss`）。**游戏与 UE 代码只在 `main`**。
⇒ T02 的"游戏真实代码"样例**只能**从 `main` 选；`sdk`/`subsdk0` 属平台库，属"重实现或替换"对象。
